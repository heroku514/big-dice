# Plan - Big Dice

## Goal

Ship a free offline dice table with huge numbers for kids, families, and seniors.

## Approach

1. Confirm App Store Connect has no rejected app waiting.
2. Build Big Dice in Expo: one to three dice, a turn total, and four saved scores.
3. Run the full simulator regression on the Release binary for build 1.
4. Take three native screenshots, then upload that binary and submit it.

## 2026-10-03 result

The store listing name is Big Dice Table. Build 1 is Waiting for Review.

## Why this app

Picture lists, outing plans, and two-player games are already in this pipeline. A pass-and-play dice table keeps the phone on the table: big faces, a running total, and a score for each person.
